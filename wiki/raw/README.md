# raw/ — מקורות snapshot

**קבצים בתיקייה הזו הם immutable. לא עורכים אותם. לעולם.**

לכאן מועתקים מקורות מסוג `snapshot` — כאלה שעלולים להיעלם או להשתנות מחוץ
לשליטתנו: מסמכי עיצוב, שרשורי דיון, מיילים, תמלולים, מאמרים חיצוניים.

מקורות מסוג `live` — קוד הריפו ו‑`docs/` — **לא** מועתקים לכאן. הם נקראים
במקומם, ודף המקור ב‑`pages/sources/` רושם את הנתיב ואת ה‑commit שבו נקראו.

ההפרדה הזו קיימת כי ב‑Wiki על פרויקט קוד חי, העתקה של קוד לתוך `raw/` יוצרת
עותק שמתיישן בשקט. עדיף להצביע על המקור ולתעד נקודת זמן.

## מוסכמת שמות

```
YYYY-MM-DD-slug.ext
```

התאריך הוא **תאריך המקור**, לא תאריך ההעתקה. אם אינו ידוע — תאריך הקליטה,
ומציינים זאת בדף המקור.

## התהליך

מעתיקים לכאן **לפני** הקריאה, כדי שמה שנקרא יהיה בדיוק מה שנשמר.

כרגע ריק — המקור היחיד שנקלט עד כה הוא `live`. ראו `pages/sources/`.
